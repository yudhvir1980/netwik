Agents are built on three things.

A smart model is not enough. An agent can only work on a network when all three of these are in place, and every use case here shows them.

01

Context

What your people know about the network, its sites and its processes, written down so that an agent can use it.

 02

Foundation

Connections to the tools you already run, such as the service desk, monitoring and controllers, and a platform for the agent to run on.

 03

Autonomy

Clear limits on what the agent may do on its own, what needs an engineer to approve, and what it never does.
